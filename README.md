## Sistema Web de Gestão de Tarefas
Projeto inicial para organização de tarefas.
## Objetivo resumido
Configurar a estrutura inicial do projeto backend em Python, estabelecendo o isolamento de dependências com ambiente virtual e versionamento correto via Git.
## Pré-requisito
Python 3 instalado.
## Execução
Crie o ambiente virtual:
python -m venv .venv

Ative o ambiente virtual:
.venv\Scripts\activate

Execute:
python main.py
